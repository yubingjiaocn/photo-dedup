# Current failures: targeted research and minimal A/B

Scope: only the three observed failure classes below. All experiments are cached-feature, read-only and shadow-only. Disney/JX3 are tuning inventories; Lin held-out is excluded. No external code or model was imported in this iteration, so there is no new runtime code/model license.

## A. Fixed-stage background links distinct action states

- **Bad example:** a Disney stage camera remains fixed while performers, count and pose change. Whole-frame DINO neighbours form an A~B~C chain even though A and C are different moments.
- **Hypothesis:** adjacent state change is more reliable than similarity to a static background. A logical phase boundary should combine time, embedding, detected-face count and detected subject/face position. Group span and representative-purity guards remain necessary because logical phases do not physically split the DB group.
- **Targeted method check:** Truong, Oudre & Vayatis, *ruptures: change point detection in Python* (2018), [arXiv:1801.00826](https://arxiv.org/abs/1801.00826), frames offline segmentation as change points in multivariate non-stationary signals. Its cost/model/penalty would create another tuning surface. Video shot detectors were rejected because edited-shot cuts are not sparse-photo action phases.
- **Minimal A/B:** existing DB groups are held fixed. Baseline = one group keeper. Candidate = adjacent multichannel logical phase annotations plus at least one keeper per phase. Report multi-phase groups, changed keeper groups, retention and review members; visually inspect the emitted review queue.
- **Decision:** **adopt** deterministic adjacent change evidence and logical-phase protection now. **Reject/defer** `ruptures` dependency until labelled tune events can compare boundary precision/recall and select a penalty without held-out leakage.

## B. Multi-stage interaction receives one keeper

- **Bad example:** the 16-frame interaction sequence (approach/side hug, turn/lower, tighter hug/head-pose change) is one visual group and previously receives one keeper.
- **Hypothesis:** keeper budget must respond to observed variation, not raw phase size. After the best-quality frame, each extra frame must trade off quality and novelty; pure farthest-point selection can retain a poor frame.
- **Targeted method check:** Carbonell & Goldstein, *The Use of MMR, Diversity-Based Reranking for Reordering Documents and Producing Summaries* (1998), [ACL Anthology X98-1025](https://aclanthology.org/X98-1025/), gives the direct relevance-minus-redundancy objective used here. DPP explicitly combines item quality and set diversity; Sharghi, Gong & Shah, *Query-Focused Extractive Video Summarization* (2016), [arXiv:1607.05177](https://arxiv.org/abs/1607.05177), also argues that individually important and collectively diverse items are separate requirements. Facility-location/submodular and k-DPP remain useful large-summary comparators, but would add kernels/dependencies for groups that are usually single digits. No external implementation is reused.
- **Minimal A/B:** baseline = one legacy quality keeper. Candidate = one keeper per logical phase; within a variable phase, one bounded extra selected by deterministic MMR `λ·utility − (1−λ)·max_similarity`. Compare candidate retention, extra-keeper groups and review queue. Confirm a large but near-identical phase does **not** gain a keeper.
- **Decision:** **adopt** local deterministic MMR and variation-aware bounded budget. **Reject for v2** DPP/facility-location dependencies; revisit only if labelled large-event summarization shows MMR coverage failures.

## C. Wrong keeper from expression, eyes, occlusion or completeness

- **Bad example:** within a genuinely redundant burst, the technically sharp frame may contain closed eyes, blocked face, poor expression or cropped subject. Production Stage 1 currently caches `face_quality`, exposure/routing/eye-detector records, but generally does **not** cache generic `subject_completeness` or `occlusion` fields.
- **Hypothesis:** ranking must use only available evidence with weight renormalisation, preserve missing values as missing, and route uncertain cases to review. Inventing neutral completeness/occlusion values can silently reorder keepers; treating every optional omission as an extra keeper creates keep-all review overload.
- **Targeted method check:** Wang et al., *Real-time Burst Photo Selection Using a Light-Head Adversarial Network* (2018), [arXiv:1803.07212](https://arxiv.org/abs/1803.07212), reports that subtle burst ranking depends on sharpness, open/closed eyes, pose and composition; it reports top-1 64.1% and top-3 86.2%, which is evidence against pretending a universal scorer is certain. *Aesthetic Quality Assessment for Group Photograph* (2020), [arXiv:2002.01096](https://arxiv.org/abs/2002.01096), explicitly models eye state, seven-region face occlusion, gaze, pose and face blur. These are face-specific signals, not valid generic subject-completeness proxies. No new detector, code or weights are reused here.
- **Minimal A/B:** remove optional completeness/occlusion from synthetic production-shaped records and verify (1) no fabricated values appear, (2) one authoritative utility score drives keeper, decision score and margin, (3) optional gaps flag bounded review but do not keep all, and (4) only primary boundary-signal loss can add at most one uncertainty keeper per logical phase. On Disney/JX3 report actual review groups/members and inspect changed groups.
- **Decision:** **adopt** availability-normalised utility plus bounded scene/phase review. **Reject** claims that face position, exposure or missing defaults are working proxies for generic completeness/occlusion. Defer any new occlusion/eye model until train/tune labels establish incremental value and model-weight license/provisioning are recorded.
